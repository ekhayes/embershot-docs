**Step 1:** Click 'Share'

![](/img/help/2bTp7YZZAFJjkUdNBhsQ7HZjYRVqId4e1w-dee73f4a816b.png)

**Step 2:** Enter the user you wish to send the desired file.

*Note: Be sure to press 'Return/Enter' key on your keyboard in order to properly submit the entry.*

![](/img/help/nAW1LMnaDYb9wuJAvP6EnRy-K2V-jpwZw-c9c78f409ccc.png)

**Step 3:** You can adjust the expiration date of the file by clicking on the date in the 'File will expire on' field. You can also make the file available to a user infinitely by clicking the 'Never Expire' field.

![](/img/help/TjKtf1cXCEhnUV_O1MWd5Jg9mmCIOpZ3vw-37a717ab3296.png)

**Step 4:** Select the 'Allow Share' or 'Allow Print/Download' if you wish to added those security permissions to the file you are sharing. "Require Password" is selected by default and can only be unselected by upgrading to an Enterprise Account.

![](/img/help/_6ke78JCHlHTwU4BPFg9O4ynpJxgGZmN3A-67151bc19161.png)

*Note: Click 'More' to change other security permissions before sending file*

![](/img/help/Om1VXxfLLHCFkd4BCmwWie2XY0i5xKcd0g-e0b788ed0a48.png)

![](/img/help/1Jt6JUxtwZtAN0FuiajINAEBUn4kqnGxZg-3f74627ca2e1.png)

**Step 5:** Enter message for email

![](/img/help/Mq7Qt5YX7zWa6Xe3BJula18oDnYbfitXrQ-c9a558c5b66f.png)

**Step 6:** Click 'Send'

![](/img/help/4G7olC82m8w344EE6d8rBrmVTqu_OGDhbw-35a5a2257593.png)
