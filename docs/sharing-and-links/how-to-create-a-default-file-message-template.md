Step 1: Click on the 'Settings' icon for the desired file.

![](/img/help/MuIK7Ipw7CntfDoB4hjohtACMVATccvqYw-cc0827cf8416.png)

Step 2: Scroll down to the 'Default File Message' section, enter a message and click 'Update' to save.

![](/img/help/S1HeUATj7KJrvGTjKaQKBA7NF-zXF4Eljw-d3c751b83c7b.png)

When the file is shared, the 'Message' section of the Share Panel will autofill with the 'Default File Message.' To change it, edit it again in the file's Settings.

*Note: Project admins can also save a message as a template for the whole project and pick it whenever they share. See [How to save a project message template](/sharing-and-links/how-to-save-a-project-message-template).*
