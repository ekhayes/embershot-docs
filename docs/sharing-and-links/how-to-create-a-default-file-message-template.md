**OPTION 1**

Step 1: Click on the 'Settings' icon for the desired file.

![](/img/help/MuIK7Ipw7CntfDoB4hjohtACMVATccvqYw-cc0827cf8416.png)

Step 2: Scroll down to the 'Default File Message' section, enter a message and click 'Update' to save.

![](/img/help/S1HeUATj7KJrvGTjKaQKBA7NF-zXF4Eljw-d3c751b83c7b.png)

When the file is shared, the 'Message' section of the Share Panel will autofill with the 'Default File Message.'

**Note:** The default message can easily be updated directly in the Share Panel by clicking 'Update Default Message.'

![](/img/help/MtB4PLWGgYV3qwEwmLsEdGQp-Cyzozzyxw-650e594e57e1.png)

**OPTION 2**

Step 1: Click on the 'Share' button for the desired file.

![](/img/help/gVp0FGK3auf7SBAK-MebycoaBbk-GtyeSg-6561f80e5063.png)

Step 2: Enter a recipient's contact information and desired security permissions.

![](/img/help/S01As4tFJuitAPyO4gQCNm9-bBCNDrsCfw-9e2338e62bca.png)

Step 3: Enter the desired text in the 'Message' section and click 'Save Default File Message.'

![](/img/help/8dj3IOx8EBclocoTAP1RkySsstKHudqmgQ-d067778e1d0e.png)
