Default file messages have been replaced by project message templates.

Save the message you write in the Share Panel with 'Save Message Template', and title it 'Default' to have the Share Panel fill it in every time it opens. See [How to save a project message template](/sharing-and-links/how-to-save-a-project-message-template).

Files that already had a default file message kept it: it became a template titled 'Default - <file name>', which the Share Panel picks when you share that file.
