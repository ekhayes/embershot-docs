When someone shares a file with you as a link, you open it by signing in to Embershot with the email address the link was sent to. There is no code to enter. An Embershot account was created for you when the file was shared, so you do not need to register.

**Step 1:** Click the link. The Embershot login page opens and says "Sign in to view the file that was shared with you."

**Step 2:** Enter the email address the link was sent to.

**Step 3:** What happens next depends on your account:

* **You already have a password:** enter it and click 'Log In'. The file opens.
* **You have never set a password:** the password box is replaced by "You haven't set a password yet". Click 'Email me a link', open the email from Embershot Support (subject "Embershot Password Reset"), and choose a password. You are signed in and the file opens.
* **Your company uses its own sign-in (for example Okta):** you are taken to your company's sign-in page, then back to the file.

*Note: The set-password link works for 30 minutes. If it has expired, click the file link again and request a new one.*

**Step 4:** When you close the file you will see your Embershot file list, including any other files shared with you.

## If something goes wrong

* **"This file was not shared with (your email)":** the file was shared with a different address. Use the address the link was sent to (for example @me.com vs @icloud.com, or a work vs a personal address), or ask the sender which address they used.
* **"You don't have access to this file" after signing in:** you are signed in with a different account, which often happens on a shared computer. Click 'Log Out' and sign in with the address the link was sent to.
* **"Your file has expired":** your access has ended. Ask the person who shared it to extend it. See ['How to request an extension for an expired file.'](/viewing-and-playback/how-to-request-an-extension-for-an-expired-file)
* **You forgot your password:** click 'Forgot?' on the same page. The reset email brings you back to the file.
* **The set-password email never arrived:** check your spam or junk folder. See ['My emails are going into my spam box.'](/troubleshooting/my-emails-are-going-into-my-spam-box)
