**Step 1:** Click 'Share' on the desired file

![](/img/help/b3iSOMrzsVC9XiUauy8ik03QABk2CbHXQA-4eab8f8d6fbb.png)

**Step 2:** Enter the users whom you would like to allow access and select the appropriate security permissions

![](/img/help/H6L7zcUO85f10mAXdsA3aeydunKXjSE-cA-c1c1db9f0714.png)

**Step 3:** Click on 'Create Link'

![](/img/help/z0oYZlPls1TVeyAn-MBJEfeo3Dh-P9LTPw-c550832f5f39.png)

**Step 4:** The file's 'Link' popup appears.

*Notes: Click the 'Copy' icon next to the link to copy link to clipboard.*

*Click on 'Click here' to add additional link users.*

![](/img/help/68UrKZRnmmBMjzeZJVC9mPqbHgXMRzc5Fw-a68e3a3ef95c.png)

When you click to add additional users, the 'Share' panel will popup again. Enter additional user names/emails/group and click 'Update Link' to update.

![](/img/help/kIe0DxZwCq4X5T5nty5nFedFH-MUSeNx6w-5137d06b62fc.png)
