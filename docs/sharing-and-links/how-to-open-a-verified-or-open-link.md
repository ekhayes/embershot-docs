These links start with **embershot.com/v/**. You do not need an Embershot account or password, and you only see the one file that was shared.

## Open link

Click the link, then click 'View File'.

## Verified link

**Step 1:** Click the link and enter your email address. Click 'Continue'.

**Step 2:** Check your email for a message from Embershot Support with the subject "123456 is your Embershot code" (your code will be different).

**Step 3:** Enter the code and click 'Verify'. The file opens.

*Notes: The code works for 30 minutes and only for this file. After five wrong tries you are asked to request a new one. If no code arrives, use the 'click here' link under the code box to try again.*

The first time you open a file this way you may see "Preparing your copy of this file..." for a few seconds while Embershot adds your watermark.

On the same browser you will not need a new code again for 7 days, or until the link expires.

**Already signed in to Embershot?** A Verified link opens the file in your account with no code.

## Closing the file

When you close the file you return to the link's page. Click 'View File' to open it again.

## If something goes wrong

* **"This link has expired"** or **"This link has been turned off":** ask the person who shared it for a new link.
* **"This link isn't available right now":** ask the person who shared it.
* **"This link doesn't exist":** check that you copied the whole address.
* **"You no longer have access to this file":** you were removed as a viewer. Ask the person who shared it.
* **"This file was shared with your Embershot account. Sign in to open it":** the file was already shared with your email directly. Click 'Sign In' and sign in with that address.
* **The code email never arrived:** check your spam or junk folder. See ['My emails are going into my spam box.'](/troubleshooting/my-emails-are-going-into-my-spam-box)
* **"This view ended because a screenshot was taken":** on an Open link a detected screenshot ends the view. Click 'View File' to open it again.
