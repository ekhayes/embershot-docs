**Step 1:** Click on 'Viewers' for the desired file.

![](/img/help/OLUSyWQOdDnKYT_Ylct05aeHY-D1nlbftw-dfed94e6cee3.png)

**Step 2:** Click the three dot 'More' menu next to the desired viewer. From the dropdown, select 'Resend Email.'

*Note: You can Adjust Security Permissions from this dropdown before you select 'Resend Email.'*

![](/img/help/eiETl-QDoC2nHB3oVEnDfwU1b-6rItLizg-4badec31bb06.png)

**Step 3:** The 'Share' panel pops up with the recipient(s) name and previously selected Security Permissions already entered. Make adjustments, enter an email message if you choose, and press 'Send.'

![](/img/help/nP8CHQ8frDUet_oqUCQvTlknvRyE2Tv8Tw-87cbba02fdf2.png)

*Note: You can select multiple recipients in the Viewer List and resend email to all at once.*

![](/img/help/MKySskFU4NKKITJXv5hONH_2X7iDnVlbBA-b274f7080fb2.png)
