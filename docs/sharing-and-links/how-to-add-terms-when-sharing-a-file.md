**Step 1:** Click 'Share'

![](/img/help/Q9UjGp01LIB3mAQ4FWcEZ4h1a6vEt97xAA-82e9e44000aa.jpeg)

**Step 2:** Enter the user you wish to send the desired file

![](/img/help/0qKkRFyLfvfjqx5CUFwlWMAC21a4Smqz0A-86f86145fc7c.png)

**Step 3:** Open the the "More" section

![](/img/help/gVmGhl5CoZsHL13R17HSm46403DpVA_nFw-0d24990a561c.jpeg)

**Step 4:** Select "Require Terms Signature" and copy and paste your terms into the text field.

*Note: If a Project NDA (terms) has already been uploaded to the project then it will automatically appear in the Terms field of the Share Panel when you select "Require Terms Signature." For more info, see [How to Add a Project NDA](https://embershot.freshdesk.com/a/solutions/articles/73000515772)*

![](/img/help/WJ9enocyLToKp5RTEcEMyt3rxP83Fc2aFQ-b1b35888ad64.png)

**Step 6:** Enter a message for email

![](/img/help/FwW5zUSudzMrixIbthCnWbKPmQxneQ1q4w-2190b31cebb4.jpeg)

**Step 7:** Click 'Send'

![](/img/help/A-RNjXYhTtmawVKEV5RG-DdwrBP80kAVcA-bc902b24da30.jpeg)
