Links are added by the file admin, so only file admins see the link tool.

**Step 1:** Click on the link icon in the toolbar

![](/img/help/3RskTTFXWxZnjZ7r7krqE6gENJCep0tluw-e08294ef7143.png)

**Step 2:** Highlight the desired text that you wish to turn into a link

![](/img/help/PTRiTsHIOzIJQjeHbbRB0Isan172_sZNhw-3e7ce8b8a514.png)

**Step 3:** Enter the web address in the text field and hit "Save". If you leave off `https://`, it is added for you. Only web (http or https) and email (mailto) addresses can be saved.

![](/img/help/N3OErnVOBD8_AbFu0QtpsOUa5s8W9sdD_w-4118c34d8e50.png)

**Note:** A new link starts as Permanent, so every reader sees it and can click it, including people who open the file from a share link. If you turn 'Permanent' off, other readers only see the link when the file's Notes setting is 'Shared'. See ['How to add a permanent link or note that every reader sees'](/annotations/how-to-add-a-permanent-link-or-note-that-every-reader-sees).

If you let go of a new link without entering an address, the link is removed.

## Make your own text a link

Use this when the words you want to link are not in the document, for example on a scanned page or a picture, or when you want a short line like "Watch the trailer".

**Step 1:** Choose 'Text' in the annotation toolbar, click the page and type the words.

**Step 2:** Click the text box to open its settings.

**Step 3:** Enter the web address under 'Link to web address' and click 'Save'. The words are underlined, and the text box turns Permanent so every reader can click it, including people who open the file from a share link.

To make it plain text again, empty the address and click 'Save'. In a downloaded or printed copy, the text box is clickable too.
