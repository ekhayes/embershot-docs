A Permanent annotation stays on the page for everyone who opens the file: people you shared it with by name, project members, and anyone who opens it from a share link, even when notes are turned off for that link. Use it for a link to a lookbook, a trailer or an order page, or for a note every reader should see. File admins (the file's owner and project admins) can add them.

## Steps

**Step 1:** Open the file and add the link, note or highlight as usual. See ['How to add a link to a document'](/annotations/how-to-add-a-link-to-a-document).

**Step 2:** Click the annotation to open its settings.

**Step 3:** Turn on 'Permanent'. The annotation's settings now say 'Permanent', with a lock. A new link starts as Permanent already, and so does a text box once you give it a web address, so for those you can skip steps 2 and 3. See ['Make your own text a link'](/annotations/how-to-add-a-link-to-a-document#make-your-own-text-a-link).

## Notes

* Readers can click a permanent link, and it opens in a new tab. They cannot move, change or delete a permanent annotation, and it stays on the page even if they turn 'Show Annotations' off.
* To make every new annotation permanent, set 'Default Annotations' to 'Permanent'. See ['How to set your annotations to default to Public, Private or Permanent'](/annotations/how-to-set-your-annotations-to-default-to-public-private-or-permanent).
* Without 'Permanent', other readers only see your annotation when the file's Notes setting is 'Shared', and people who open the file from a share link never see it.
* To take a permanent annotation off every reader's page, delete it.
* Permanent annotations work on documents, not on video or audio files.
