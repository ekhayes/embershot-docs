**Step 1:** Click on the 'Menu' icon in the top left corner.

![](/img/help/QWv-YUYQpglMIWTMh3BhG7AWHusLTVpBNw-489fbbb05f5e.jpeg)

**Step 2:** Click on the 'Other Annotations' section.

![](/img/help/DU1UWlITVlCJGy3wTx_x6aH2v81kxQhHCA-63dbd20e7eaf.jpeg)

**Step 3:** "Check the box next to the user's name whose annotations you would like to see in the 'Other Annotations' section."

![](/img/help/8vDArxoFLHm_VIvCckNzGNfgJRVF58gaEg-a71e06bf0753.jpeg)

**Note:** "You can only view other user's 'shared' annotations when the file is set to 'Notes: Shared'"
