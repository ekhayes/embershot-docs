Annotation Sharing decides whether readers of a project's files can share their annotations with each other. It is off unless a project admin turns it on.

* **Off:** every reader's annotations are private. File admins can also make an annotation Permanent, so every reader sees it.
* **On:** readers can also make an annotation Shared, so the file's other readers can see it.

## Steps

**Step 1:** Select the project from the Project dropdown menu.

**Step 2:** Click the 'More' menu and select 'Annotation Sharing'.

**Step 3:** Choose 'On' or 'Off'. The check mark shows the current setting.

## Notes

* Only project admins (and the project's owner) see 'Annotation Sharing'.
* If your organization has locked the setting, 'On' and 'Off' are greyed out and the menu says 'Locked by your enterprise'. See ['How to set and lock annotation sharing for your organization'](/enterprise/how-to-set-and-lock-annotation-sharing-for-your-organization).
* Files that are not in a project, such as files in 'Personal', never share annotations: recipients' annotations are private, and the file's owner can make them private or Permanent.
* Turning sharing off hides annotations that were shared before; turning it back on shows them again. Permanent annotations are not affected either way. See ['How to add a permanent link or note that every reader sees'](/annotations/how-to-add-a-permanent-link-or-note-that-every-reader-sees).
