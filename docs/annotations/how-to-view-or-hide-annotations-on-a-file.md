---
**Step 1:** Click on the menu in the top left corner.

![](/img/help/I5yzul7iVgRow8BlmyjP70sQoHG9hnYZ3g-789c5786b366.png)

**Step 2:** From the 'Options' dropdown, switch the 'Show Annotations' toggle to either 'on' (orange) to show annotations, or 'off' (white) to hide annotations.

![](/img/help/Rt51ZGlZh_HMfjCT74NMHBqGOarN1GIN-A-1eff9d18d0c4.png)

*Note: You can only view other users' 'Shared' annotations when the file is set to 'Notes: Shared'*
