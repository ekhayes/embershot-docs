**Step 1:** Scroll to the file you wish to change individual annotations for and hover over it

**Step 2:** Select 'Settings'

![](/img/help/XUkBZZUu5nXH7uTLZEpC_jryX4h9yL2ntA-10ff77aa29ae.png)

**Step 3:** Click on the drop down menu under 'Annotations' and choose 'Allowed' or 'Not Allowed'

![](/img/help/Cb2NXyM5tkLR3ehKNSNFSLyMhdkEdmWBKA-87526af1acdc.png)

![](/img/help/5ZIzVU1F9ako5_-heHzXagSJdVWygSpjxw-e96c89bdf169.png)

**Note:** If annotations are set to 'Not Allowed', the annotation toolbar does not appear when the file is opened.

**Note:** Whether readers can share their annotations with each other is set for the whole project, not per file. See ['How to turn annotation sharing on or off for a project'](/annotations/how-to-turn-annotation-sharing-on-or-off-for-a-project).
