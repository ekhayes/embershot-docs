---
**Step 1:** Scroll to the file you wish to change individual annotations for and hover over it

**Step 2:** Select 'Settings'

![](/img/help/XUkBZZUu5nXH7uTLZEpC_jryX4h9yL2ntA-10ff77aa29ae.png)

**Step 3:** Click on the drop down menu under 'Notes' to change to the desired setting of 'Individual,' 'Shared,' or 'Not Allowed'

![](/img/help/Cb2NXyM5tkLR3ehKNSNFSLyMhdkEdmWBKA-87526af1acdc.png)

![](/img/help/5ZIzVU1F9ako5_-heHzXagSJdVWygSpjxw-e96c89bdf169.png)

**Note:** "If notes are set to 'Not allowed' the annotation toolbar will not appear when you open the file."

You can only view other users' 'Shared' annotations when the file is set to 'Notes: Shared'
