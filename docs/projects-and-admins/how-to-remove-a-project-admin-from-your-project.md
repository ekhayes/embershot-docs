**Step 1:** Go to the Groups and User section of your project

![](/img/help/VmKMaszskzO-eekpl7nLjLhVhz5vgZMmQA-118fdd793216.png)

**Step 2:** Click on the menu icon next to the user's name

![](/img/help/cwbo2PqIp8QKSAjtspaF5_coCZnEBSfPtA-b0241ab4f07e.png)

**Step 3:** Select "Remove Admin Access" in the dropdown

![](/img/help/hrRp97TTCrU54yDdxXz1Hnj25G5flcnS-w-b081ce96e0bd.png)
