The Project Owner holds financial responsibility for all Project fees. **Ownership can only be transferred to another Project Admin who has an active Pro account and an up-to-date credit card on file.**

Project Ownership is indicated by a Crown icon, visible in the Project dropdown menu next to owned projects and in the Groups/Users list beside the Owner's name.

## Transfer Steps:

**Step 1:** Select the desired project from the Project dropdown menu

![](/img/help/k3s83a_g1Hx5Y23u1cVTzjfaWnSi7TYuRw-bce1708832b4.png)

**Step 2:** Go to the Groups/Users section

![](/img/help/S5c_PzwJ5rHCBsTRhLu9bGjW4qyJY_ncSg-37b16cec5833.png)

**Step 3:** Mouse over the user you would like to transfer ownership to and open the More menu next to their name.

![](/img/help/4pVfZRLXj_piq2Uf8GcW6FKcaag5zzI8xQ-8f55696dafcb.png)

*Note: If the user isn't already in the project, click the 'Add New User' button in the bottom left to add them before continuing. Make sure the user has a Pro account.*

**Step 4:** If the user isn't already an admin, from the 'More' menu select 'Make a Project Admin.'

![](/img/help/s5tGBlPCY7lNT_pM8ZPKeBk-9Wp18aCLhw-5042d0415d82.png)

**Step 5:** Once the user has admin status, open the 'More' menu again and select 'Make Project Owner.'

![](/img/help/ayBKK7LXqBev85V6iLA5B3_ONaMsihU_ug-47559d3c333c.png)

**Step 6:** Confirm that the transfer information is correct and click 'Transfer.'

![](/img/help/6YOFSC4QYJpFVvtN19bzU9zdKeXOdpN5jg-9ac131f6ad3b.png)

**Step 7:** When the transfer is confirmed the new Owner will be moved to the top of the list and the crown icon will be moved to their name. If the name is not moved to the top of the list, refresh the page.

![](/img/help/rSmVvixkLss96IXs987MNJCWyDdyZ1urEw-c15c2cb9a0c2.png)
