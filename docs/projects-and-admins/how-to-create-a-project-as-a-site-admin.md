**Step 1:** Click "Create Project"

![](/img/help/1VZh2YiJsKT6fRATfFUB6l664-PHZxMB1w-cc482fb693e0.png)

**Step 2:** Type in the name of your project and click "Create"

![](/img/help/IwwYoAUlWZLsEgwG9_LIjgoF8lh0BADeA-595e33e22687.png)

After you create the project you can [add additional project admins](https://help.embershot.com/en/projects-and-admins/how-to-add-an-admin-to-your-project-how-to-add-an-admin-to-your-project) or remove yourself as an admin.
