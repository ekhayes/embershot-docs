**Step 1:** Click on the 'Groups' icon. Ensure that you are toggled to the correct projects page for the project that you wish to add a new Admin.

![](/img/help/27g67-TLuJ0xWCjmNBZ8S4PelTVIPwVe1w-9f8f8ff7d84f.png)

**Step 2:** Click "New User."

![](/img/help/636TGtG6MFBi3HgvHN04rTLVWUUj1cQnbA-e37d1520ef93.png)

**Step 3:** Fill out fields for new User and click "Add" button.

![](/img/help/nhnswbKP6mMMRFngi8bKi0iGL72kbJ0XLQ-92b76c966876.png)

**Step 4:** Hover on the desired user and click three dots. From the dropdown, select "Make Project Admin"

![](/img/help/2FQJGVAJ01b-VASWv55BaunD1mOSC_7x-A-28c2a3a74b36.png)
