By default, Site Admins only have access to projects they create or projects where they have been added as a Project Admin.

Site Admins can view all projects on their Enterprise Site, but projects they are not assigned to will appear grayed out. To access one of these projects, follow the steps below.

**Step 1:** Open the Project List and select the grayed-out project you want to access.

![](/img/help/yBEW8f29kY8w-SQYjhtLLPmHm25TnIobnw-5c8411624a98.png)

**Step 2:** The project will appear blank. Open the Project menu.

![](/img/help/Ys4QgmfhRjf-JjWoWOEMucCWm9nMsXcC_A-5cb9fceacf0a.png)

**Step 3:** Select **Add Myself as Project Admin**.

![](/img/help/t7zFukYARCKbFrHITQbkF9gpFEGYUYx5dQ-a7763d9c3c5d.png)

**Step 4:** Confirm by clicking **Add Me.**

![](/img/help/HGmnL7yVLB-v9JYeFJ_-H6fwVxHcSQgFgA-514b5d09ecd0.png)

**Step 5:** Wait a moment or refresh the page. The project will load, and you will automatically be added as a Project Admin.

![](/img/help/ITPoBbkfIAlOQtFyKzco6Xm8043jVyh_3g-a6f8e399ec41.png)

![](/img/help/HXYH7z8ufQoxgxSVPbA3Z7nvcsjb6RS7Jw-eb037201a3ca.png)
