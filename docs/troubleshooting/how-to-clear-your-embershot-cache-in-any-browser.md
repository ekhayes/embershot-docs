You can clear your Embershot cache by clicking on this link: [Clear Cache](https://embershot.com/outside_handler.aspx?type=wipe)

After clicking on the link, you will get a blank screen that says "Your browser cache has been cleared for Embershot." When you see this message, please click on the ["click here to login"](https://embershot.com/outside_handler.aspx?type=wipe) button (instead of clicking on a link in an email) and let us know if you still experience the issue.

If you continue to have issues after checking the steps above, please let us know the following so we can better assist you:

1) The name of the file(s) you are trying to open.
2) The type of device (Mac/PC/iPhone/Android Phone/iPad/Android) on which you are accessing the file.
3) The browser version you are using or the App version you are using

* If you are using a computer, please let us know what browser you are using and the browser version. Note some older browsers may require an update to access the file.
* If you are on a phone or mobile device, please make sure you're using the app's latest version. To be sure, you can always delete the app and reinstall it.
