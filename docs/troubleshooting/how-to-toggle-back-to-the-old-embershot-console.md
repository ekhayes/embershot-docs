If you are running into an error in the new Embershot Console, please try toggling back to the old Embershot Console to see if the issue you are experiencing is also present in the old console.

**To get back to the old console:**

**1. Click on the Account Settings Icon**

![](/img/help/L8EnOjG1fbXuhOwhCkkWDNjUzJ4qZ_6iQQ-4544abc78742.png)

**2. Select 'Old Embershot' in the dropdown**

![](/img/help/_rdT1thdPfoDJ3Wa1ZDSBKz_OX4eOaKqOQ-f5147a2da95d.png)
