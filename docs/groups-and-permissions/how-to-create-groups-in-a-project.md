**Step 1:** Click on the Groups icon.

![](/img/help/AHsCzyHs5W6WLbPWdnp2Ie4oHkiNnoOIiw-cd932a0c5815.png)

**Step 2:** Click on 'New Group.'

![](/img/help/fMjYOUztVjeG_dPXX3J9xZgDGRlUodrKvA-3db73e2dddde.png)

**Step 3:** Enter a name for the new group and click 'Save.'

![](/img/help/Cy9F8n3poHzeYSjAPv0yKKuTKecwwSScHw-1b8c551dd19d.png)

**Step 4:** Add the desired users to a group by clicking on the users you wish to add to the new group. If the users are not already on the list, [add the users to the project list](/groups-and-permissions/how-to-add-new-users-to-a-project). When the users are selected, a teal highlight will appear around their names.

[![](/img/help/mksMFveg87sjpkZKTZ1Q87cgIaqxqUjetQ-b385fc090665.png)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73028357761/original/Ow9HZao2w-_HvAHLIeoVF01FJGG7ZnLlHg.png?1666204066)

**Step 5:** When all of the desired users have been selected, click on the "Add User" icon next to the group you wish to add the users.

[![](/img/help/CF2NV4dYSpH2Cg8gwZSIKILgzrLkUstBnw-60a6a76ae518.png)](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/73028358310/original/Vp6jv2P7SWydX6g-axSrBqm_5JX8YvPlWw.png?1666204202)

**Note:** "You cannot add project admins to groups because they already have access to all of the project files."

You can also [add users to groups from a files' viewer list](https://help.embershot.com/en/groups-and-permissions/how-to-add-all-of-the-users-who-viewed-a-file-to-a-group-how-to-add-all-of-the-users-who-viewed-a-file-to-a-group).
