**Step 1:** Click on the Groups icon.

![](/img/help/F2WBuoG85JmQlIpYn2yCoQFI8hjBh4OLkQ-bb982ecff862.png)

**Step 2:** Select the Group you would like to add the users to.

![](/img/help/aACCLS-kktmDoP66qoCnOjU7O-DWfFJsnQ-908bdd03d5d7.png)

**Step 3:** Click 'Add Bulk Users'

![](/img/help/d_hczew36Gbuuk_TmjJhhdLl0u6OVv_tWg-f7d141e655b3.png)

**Step 4:** "Paste the list of emails that you would like added to the Group. Select whether you would like users notified that they have been added to the group. Then click 'Find Emails' and follow prompts to add the users."

![](/img/help/FEQHiM68jYGQz1uym9K7sgaEU3cV0vysfg-6588ff5be75f.png)
