---
**Step 1:** Select the Groups/Users section in the main console.

![](/img/help/GBMUk0qovd5C4H8rb7ZyX0jM0WKrpo1uUg-4739ce84955c.png)

**Step 2:** Click the 'More' menu next to the Group that you wish to copy.

![](/img/help/fGB9AnTzM8_cBKF5ZATqoFG7ApbA78rdcQ-ab2f97693be8.png)

**Step 3:** Select the 'Copy Group to Another Project' menu item.

![](/img/help/vQPysJrDqk5U71q2n5pqzrtyCPWWZ4pgjA-8163323ef0fc.png)

**Step 4:** Click the dropdown menu to select the project to which you would like to copy the group.

![](/img/help/lNMvjbtpyo4odeBBHNkzoQhf8D7xeP5k9g-a60608f78687.png)

**Step 5:** Once the Project is selected, click 'Copy.'

![](/img/help/2ox2jOWG__c_4996Egb2uEmaSPgbjOh2Vg-8a86da581bd8.png)
