**Step 1:** Click on the 'Viewers' icon under the file name

![](/img/help/xw_XT8_3CsX2kMzw6x3N6bM9GsHgc_I2gg-0d96fd0a56a8.png)

**Step 2:** Click on the name of the user you wish to edit.

![](/img/help/TepriwnXnpT46_9ky8tdcQ3O78YsziMxiw-d91b1c4f53d9.png)

**Step 4:** Edit User's Name in the text field and select 'Save.'

![](/img/help/WIq7Z5yARDwd8XSUB-GAz7MwyEo_67_u-Q-ecacf5c69e51.png)
