**Step 1:** Click on the 'Groups/Viewers' section, hover over the name of the user you would like to edit and click on the menu icon.

![](/img/help/REn7RzGN3aC2NGr_q72mKLcWoDdw4J7g1w-12034eef6afc.png)

**Step 2:** Select 'Edit user' in the dropdown

![](/img/help/ilKf-YphD97KxXo33bWkPWlFrRSkxwRCLA-a9b4f01962e0.png)

**Step 3:** Edit the user's name in the text field & select 'Save'

![](/img/help/srKUKnNbA_cx6Hu_b5fhfc0wz6KS9K1TJQ-9f40bdd219be.png)
