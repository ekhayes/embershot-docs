---
**Step 1:** Click on the desired file's viewer list icon

![](/img/help/GlplPnIuVFUS0kxhZKoHhstwJyDXXYAJUw-86e7fad008cf.png)

**Step 2:** Select the users you would like to add to a group

![](/img/help/B7ivJBrbnhb3QY2tCKCGna8yJ5gKwT0vOQ-bcc13f46e856.png)

**Step 3:** Click on the "Add users to group" icon

![](/img/help/Y2zuwSGXlyI6CZwFxxZ_msAJYn8C_C0IDQ-120dc4f373e7.png)

**Step 4:** Select the desired group to add the users to

![](/img/help/c3w2Q7opcF1ig7BKVogmpfgdgS81pJE4mA-11a4e8d78d16.png)

You can also [add users to a group from the project user section](/groups-and-permissions/how-to-add-users-to-a-group).
