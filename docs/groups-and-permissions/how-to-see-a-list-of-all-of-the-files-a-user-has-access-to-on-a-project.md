---
**Step 1:** Click on the 'Groups' icon.

![](/img/help/NYN8fXGkvUKYKp8vOWI239FqBF35qzwP4w-d39031c264ba.png)

**Step 2:** From the dropdown of the desired user, select 'View Files.'

![](/img/help/0iTmxg2YFXL1xwucPt3svuFcUKH8TYPEfw-ea214271e5fe.png)

**Step 3:** This will take you to a page displaying all of the content that the user has access to.

![](/img/help/WepfHIIblPQlve2iNLqElBLmIjS2QowtdA-5b6be57aacef.png)
