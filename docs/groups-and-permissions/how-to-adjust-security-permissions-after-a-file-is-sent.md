**Step 1:** Click 'Viewers'

![](/img/help/YuEcD-iv5JxJsbZb0OBCGufndpFSFmOj5A-5a3287fedb5d.png)

**Step 2:** Click the appropriate permission icon for the user whose settings you wish to adjust

![](/img/help/auI8O9xSm3WlZBGhRpeYUlSgRM2oK4qF7g-abe19e9e90f7.png)

**Step 3:** If the desired permission icon does not appear under the 'Permissions' column then click the 'More' menu

![](/img/help/HXN2iv6IRap-FePb4j8J113yCTvHPetFBA-b148513bee3a.png)

**Step 4:** Then click 'Adjust Security Permissions'

![](/img/help/NNXGgJTs7Cg2JOOfJusij2pbMTV0t-sTZw-7e4c42780ae3.png)

**Step 5:** Check/Uncheck the boxes for the permissions you would like to adjust

![](/img/help/i8k2Xi7Nx3AwF3IZLeM7EJ0GrkOECj2RUQ-2c02560e4658.png)

**Note:** You can also make a file available, revoke it from a user, or expire a file for a user by clicking the drop down menu in the 'status' field. You can adjust the expiration date by clicking on the date in the 'Expires' field.

![](/img/help/sTg0boKeBtpddYBXucfdDqFRdFjJrVMJlw-e2e1376a9103.png)

![](/img/help/UzRgk8yIeSCGZvtS26zWUQRXG-R5Rh4iUQ-f190092b768d.png)
