Advanced File Tracking is a feature that Enterprise users can use to gain more insight into how their users are engaging with their content.

Pro users can also upgrade individual files to access the Advanced File Tracking features for a one-time price of $19.99 per file.

**Highlights**:

* See the page number or timestamp of where users stopped viewing your content
* See the average number of time spent on each page

**To add Advanced File Tracking to a single file within a Pro or Lite User account:**

**Step 1:** Mouse over the file you would like to track and click on the 'More' icon

![](/img/help/dsnCb1dBy7cdpKE7cEMsgSrHo8XvvirgBA-fa61db123dd0.png)

**Step 2:** Select 'Add Advanced File Tracking' from the dropdown menu

![](/img/help/79ujN4j7VroJFcUUchtD_r2wbRNvzUS9fg-6426ae2c3024.png)

**Step 3:** Enter payment information or if a credit card is already on file, click the 'Add' button to approve a one-time charge of $19.99. (*Note: Tracking features will apply to THIS FILE ONLY*.)

![](/img/help/DXi44Q4imwkjhT9r0o5hzqa5ZIeL7dy8LQ-291b70dff2c6.png)

**Step 4:** Once you have added the Advanced File Tracking to your file, you can access its features at any time by selecting 'Advanced File Tracking' from the file's 'More' menu.

![](/img/help/ig6JvD6YKcY0jBX_8C8XbvjWg-d92d8c15f366.png)

Or by clicking on the teal 'Advanced File Tracking' icon on the file:

![](/img/help/GLo8oPFZsqZTfwInOpySjKg-xK_2mvZjBQ-0a1b0c4a3a9a.png)

You can also access the 'Advanced File Tracking' features from the 'File Settings' panel:

![](/img/help/PoEtVEUljLJbMnT_bFkkm-CD7N8MPAftzw-3b448ee8425f.png)

Or in the file's 'Share' panel:

![](/img/help/qx2jBnCME3oJWRP_rO-rso9DjCQ-qHChrQ-a30af671eaae.png)

**Step 5:** View the advanced tracking analytics

![](/img/help/qXwVBFhKpbaqpj1WS7C_azVT58yNAaTtLQ-9aff2c6e1d6b.png)
