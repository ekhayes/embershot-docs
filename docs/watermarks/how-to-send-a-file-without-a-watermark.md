**Step 1:** Click 'Share' on the desired file.

![](/img/help/1jfZgB_O6c-VUD8_t-jk5JlMrF2Tlo1oiA-95626d7bbe74.png)

**Step 2:** Make sure the 'Watermark File' is unchecked.

_Note: The 'Watermark File' security permission may be found in the 'More' section._

![](/img/help/XIYOZHsP3tA3bbKqGc3OuuJCL0K-4v-7dQ-210530cdc7be.png)

**Step 3:** Send file with other desired permissions.
