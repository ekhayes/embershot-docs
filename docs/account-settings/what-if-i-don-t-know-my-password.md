If you have forgotten your password, or were never prompted to create one during your first time using Embershot, there is an option to recover/create one using the 'Forgot?' button on the login page.

**Step 1:** Click the 'Forgot?' button in the Password entry field.

![](/img/help/abZFWpEApMcWY-mAdqYdJDWaW-q7mjrcwQ-108d166069a3.png)

**Step 2:** Enter the email address or mobile number associated with the account, and click the 'Request Password Reset' button.

![](/img/help/1OzPX_C_w0_1CyDMU4ENUEWXdVSPKfaakQ-36479a1cedf1.png)

**Step 3:** Check your email inbox for a password reset email from Embershot Support. Click the 'Password Reset' button. *(Note: The password reset link will expire after 30 minutes, at which point you will need to request another reset link.)*

![](/img/help/907ju4Zvn6NoULJQIYkS-52a5b9syTeOrA-ee5ff652c93b.png)

**Step 4:** Create a new password, making sure to meet the minimum character requirements. When the newly create password entries match click 'Set Password.'

![](/img/help/R4Lv91p19GfAbJixsv7TxUgm_KHmiHYSeA-f2ad2e485bdc.png)

**Step 5:** You'll be brought back to the login page. Enter your new password and click 'Login.' *(Note: If you select 'Register' then you will receive a Duplicate Registration notice.)*

![](/img/help/5jDmcu57Xe3HjXXfKktecVFUU3Gm9PcHsA-2c0a68fb91ba.png)

If you have received a file, but have not set up your password yet, open the email containing the sent file and select the 'View' button. You will be redirected to the login page for Embershot. Click "Forgot?" and set up a new password for your free account.

**Note:** "If you received a file and was not prompted to create a password upon initial login, please DO NOT select the 'Register' button." The system automatically creates an account associated with your email address or mobile number when the file was sent to you. If you try to create another account with the same email you will receive a Duplicate Registration notification.
