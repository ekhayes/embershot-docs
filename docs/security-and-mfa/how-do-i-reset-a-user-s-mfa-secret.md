_**Note:** Only file, project and site admins can reset MFA secrets. If you are not a project or site admin, you will need to reach out to the project or site admin associated with your account or the person who sent you a file._

**Step 1:** Click on the 'Viewers' icon

![](/img/help/MlS19DukXADQC5ZVvaBZDQYWGbWT7VlUeQ-f227a0379e6f.png)

**Step 2:** Click on the three dot 'More' icon next to the desired user's name. Then select 'Initiate MFA Secret Reset' in the dropdown. This will send the user an email with a 'Reset' link.

![](/img/help/XKTC-Mx7r8VZgEKLGf2pd_yhXjTbfxdASg-3d19f0b98841.png)

_**Note:** If you are an admin and see 'MFA Not Set Up' next to the user's name, that means the user has either not set up the authenticator yet, or someone else has reset it for them._

_Also, note that if you reset the MFA Secret for a user, you should also tell the user to delete any previous Embershot codes they have stored in their Google Authentication app. You can give them the link to the following FAQ guide:_ [How to reset your MFA secret](https://help.embershot.com/en/security-and-mfa/how-to-reset-your-mfa-secret-how-to-reset-your-mfa-secret)
