You can require an additional security code to further protect your files. When this permission is set, recipients will need to enter the custom code before the media will open.

**Step 1:** Open the Share Panel for a file by clicking the 'Share' button in the media tile

![](/img/help/EbgEuePgL824_Mvnbh68MffDiscrwyLk2Q-726cda42aa80.png)

**Step 2:** Once you have entered the recipient email address select 'Require Extra Security Code,' which you will find inside the box labeled, 'More.'

![](/img/help/8hT_AVMX9x5kDbaVg_MHWV6LJ3lE47fe9Q-21225fc19973.png)

**Step 3:** Set a custom security code.

![](/img/help/NNMDsOYT8_YCN5Y2FtxHr07H-u5H_9Oyvw-98af565fafff.png)

![](/img/help/bAX4pFOorLTNHZ9tuvBsSgz1RqWnmo6iqQ-35734c2bb64b.png)

**Step 4:** Enter the Email Subject and Message fields and press 'Send.'
