_Note: Only file, project, and site admins can reset MFA secrets. If you are not a project or site admin, you will need to reach out to the project or site admin associated with your account or the person who sent you a file._

**Step 1:** Go to the Groups and User section of the Site Admin project.

![](/img/help/5wg_gsvDHuhjwySqPEL170DUib790oRe0g-6af1c73a6787.png)

**Step 2:** Click on the menu icon next to the user's name

![](/img/help/kXOxNC2kqCo9zOmrxT5aFqTBIa9yQvLbpA-647f740ccfbc.png)

**Step 3:** Select "Initiate MFA Secret Reset" in the dropdown

![](/img/help/fWofg1RFPuc_SeBfEG368eZ7AFmZjag5yg-81b4d58f628f.png)

_**Note:** If you are an admin and see 'MFA Not Set Up' next to the user's name, that means the user has either not set up the authenticator yet, or someone else has reset it for them._

_Also, note that if you reset the MFA Secret for a user, you should also tell the user to delete any previous Embershot codes they have stored in their Google Authentication app. You can give them the link to the following FAQ guide:_ [How to reset your MFA secret](https://help.embershot.com/en/security-and-mfa/how-to-reset-your-mfa-secret-how-to-reset-your-mfa-secret).
