If you are getting an error message that says your MFA code is incorrect, you will need to troubleshoot the Authentication App. This Authentication error message is coming from the Authentication App, not Embershot. The code you entered does not match the code being reported to Embershot. This could be due to several factors, including:

* Typing in the code incorrectly.
* Not entering the code within the 30 second time limit.
* Your device is not reporting the code within the 30-second window. See ways to troubleshoot the Authenticator App here: [Top 5 Ways to Fix Google Authenticator Not Working](https://www.guidingtech.com/fix-google-authenticator-not-working-iphone/) and also [How to Generate Backup Codes on Android](https://www.makeuseof.com/tag/google-authenticator-codes-stopped-working/) if you are on an Android.

Remember, if you need a new QR code and/or need to reset the MFA secret for any reason, you will need to ask your file, project, or site admin to reset it for you. You can also reach out to your Enterprise Site Support for additional assistance with the Authenticator App. You can contact them directly by clicking on their support link.
