You can add additional security to your files by requiring SMS authentication. When this permission is set recipients must login and then complete a text message authentication before gaining access to the media.

**TO SEND**

**Step 1:** Open the Share Panel for a file by clicking the 'Share' button in the media tile

![](/img/help/C8YY_OghzBxp4tPbcND-hYFwPDYkQSZDHw-8234008eda54.jpeg)

**Step 2:** Once you have entered the recipient email address, select 'Require SMS Authentication,' which you will find inside the box labeled, 'More.'

![](/img/help/yhsXnwUXuWQZ0S-9nKHXSC_9uJGTu7fLcQ-29acff9d06c1.png)

**Step 3:** Enter the Email Subject and Message fields and press 'Send.'

**TO OPEN**

**Step 1:** The recipient receives an email with a link to the file.

![](/img/help/V6TYROBOk7Wn7-P5agxNfW6yePhAJZqrBQ-9b8efe54e6e0.png)

**Step 2:** The recipient clicks 'View', is taken to the Embershot login page and prompted to enter their password.

*Note: If they don't have an Embershot account, they will be prompted to create a password.*

![](/img/help/ggEkrroDpmGvKjM2pfoO8QaB2ttx0uj6ow-1c3fb4564125.jpeg)

**Step 3:** Once logged in the user is prompted to enter a mobile number for multi-factor authentication.

![](/img/help/E0WXyS2mHRWLuzXjHMdKaRIIyHdGt8284Q-68776ad16815.jpeg)

**Step 4:** User enter mobile number and a verification code is sent to their phone. User enters the code and once accepted the file opens.

![](/img/help/qIoHqj2t_b2b-wGobXCS4IGQUePwTn9xsg-25492f9a1e9f.jpeg)
