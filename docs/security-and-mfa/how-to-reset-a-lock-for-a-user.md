---
**Step 1:** Click on the 'Viewers' icon for the desired file.

![](/img/help/WqSbenMB36P8Q18bkfpWoRLKHvnh2VJg-w-a4f3cf0892f9.png)

**Step 2:** Locate the desired user and click the teal 'Lock' icon listed under 'Permissions.'

*Note: The 'Lock' icon turns from gray to teal when the lock is triggered.*

![](/img/help/R7w6t4WyouFT62cTE0msPvKIL2c24b319A-a3bbd4c788aa.png)

**Step 3:** Select 'Reset Lock' from the dropdown menu.

*Note: If the user has not triggered the lock, the 'Lock' icon will remain gray and the 'Reset Lock' option will not appear.*

![](/img/help/FnsDeXWdy3Wu_I7ZJ04os_UtMRN24lOb1A-2dc270745fec.png)

**Step 4:** Once the lock is reset, a confirmation will appear and the 'Lock' icon will turn back to gray.

![](/img/help/T4ffwQ3E4KYRvEgaYe1lXSu1mlk-HXEERg-63641eb8462f.png)
