If your file has expired and you no longer have access, you can open your Expired folder and send a file extension request to the sender.

**Step 1:** Open Folder tab

![](/img/help/C1hJnfkzIs7FsWmwH7MarTcsU1sbXqFohQ-fa4edc8e73c4.jpeg)

**Step 2:** Select and open the Expired folder

![](/img/help/bWRr3-AHLqULkFzwceLks7QVsS5Mag6aXA-b67d01a50ee6.jpeg)

**Step 3:** In the Expired folder, hover over the file you would like to access and click the 'Request Extension' button

![](/img/help/ApWLLd1nCT_XKa74trmO_wkUnRLOcU6adg-958a34396399.jpeg)

**Step 4:** Click 'Send Request'

![](/img/help/4f2zs2qVgf3XHD2EkJ3KPSUeaCXFi3yeEg-54927e8b5c95.jpeg)
