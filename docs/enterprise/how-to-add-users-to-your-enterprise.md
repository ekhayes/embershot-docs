Only **Enterprise Site Admins** have the ability to add users to an Enterprise site.

**Step 1:** Toggle to your site admin project

![](/img/help/i9-vsgm8XzVLpUUXRgUVgyQakG_w0D10rQ-9402d6234f18.png)

**Step 2:** Click the icon to add a New User

![](/img/help/_SEBQ1ZriYRfxEpRUcBLGLazNnw6XAHykw-3f322cb932ef.png)

**Step 3:** Fill out the form fields and click dropdown menu to either add and close the pop-up, or to add and continue adding additional users.

![](/img/help/kyJiFYHuaDZ3t2Ev1P-_QRibIK5q-mTzjA-c14cccf2c7f5.png)

**Note:** If you receive an error indicating the user exists on another site, contact [support@embershot.com](mailto:support@embershot.com) for assistance relocating them. Users with unaffiliated domain names must provide authorization before you can manage their account.

You can also add users in bulk by clicking the "Add Bulk Users" icon.

![](/img/help/PC9T4y5FYzMzieELlLbfENEMtdnZwbfK6Q-364acb6854df.png)

![](/img/help/A4-N6KVLc71NTv6j4I9Ziazj09vnJX5x2w-82aa3e35cdd4.png)
