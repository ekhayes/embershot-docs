Only **Enterprise Site Admins** have the ability to create and lock default watermark settings for all users on an Enterprise site.

**Step 1:** Log into your Enterprise Site Admin account and select the Site Admin Project from the Project dropdown menu.

![](/img/help/oOTS1vSKsiB-UpLYH_XDYe7Dw0kKkYr4Xw-40977477102b.png)

**Step 2:** Click the 'More' menu and select 'Enterprise Site Settings'

![](/img/help/Ns2dbr33tA15fgEwiC1pMdHYOiVJ4JWyRA-2689337d10e2.png)

**Step 3:** Set your preferred Watermark for the site and then set the File Sharing Setting for the site

![](/img/help/8o8weN61aYFFb2wWl0rSuxAyLQJQA9XDGQ-6ab779c34d4e.png)
