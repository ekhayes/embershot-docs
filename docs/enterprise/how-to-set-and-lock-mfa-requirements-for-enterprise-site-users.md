Only **Enterprise Site Admins** have the ability to set and lock Multi-Factor Authorization requirements for all users on an Enterprise site.

**Step 1:** Log into your Enterprise Site Admin account and select the Site Admin Project from the Project dropdown menu.

![](/img/help/1gfE9TokhakMGiiSYBZBqkYRy-xrqZHTTA-15b0a51bd497.png)

**Step 2:** Click the 'More' menu and select 'Enterprise Site Settings'

![](/img/help/eL4e9yQS85qSI2XDLaz9nrtZjI1-EXV5Zw-b945d1ca6a80.png)

**Step 3:** Set your preferred MFA settings for the site. Your company's Enterprise Support email address and phone number are required, as security protocols prevent Embershot Support from managing or resetting MFA secrets.

![](/img/help/Iny7t4vabUyLg5Wf2gMV9MWABo869ES6vA-cc3fd51ba269.png)
