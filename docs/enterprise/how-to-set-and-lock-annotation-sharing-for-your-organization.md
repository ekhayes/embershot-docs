Only **Enterprise Site Admins** can set annotation sharing for every project on an Enterprise site. It starts as 'Locked Off'.

**Step 1:** Log into your Enterprise Site Admin account and select the Site Admin Project from the Project dropdown menu.

**Step 2:** Click the 'More' menu and select 'Enterprise Site Settings'.

**Step 3:** Under 'Annotation Sharing', choose one:

* **Locked On:** readers in every project can share their annotations with the file's other readers.
* **Locked Off:** annotations are private in every project. File admins can also make them Permanent, so every reader sees them.
* **Not Locked:** each project's admins decide. Projects start with sharing off. See ['How to turn annotation sharing on or off for a project'](/annotations/how-to-turn-annotation-sharing-on-or-off-for-a-project).

**Note:** Your site admins get an email when the setting changes.
