Yes! You can upload a password-protected PDF. After a file is uploaded, you will need to enter the password into the system.

**Step 1:** Upload the password-protected PDF.

**Step 2:** Click on the "More" menu for the file you wish to add a password to

![](/img/help/j5dMsR7YhqGIsnyuvfEFgH4FxYjRhH_cDw-d804f8f1f2aa.png)

**Step 3:** Select the "Original File Password" option, enter the password, and click "Update."

![](/img/help/a-pghMD3HnmiHoeEg6zlhbNY1W0g46ODoA-1516f4ba9b8e.png)

_The system does not support other password-protected files (like .DOC, .JPEG, .MOV, etc)._
