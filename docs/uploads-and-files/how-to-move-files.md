**Step 1:**  Select the file(s) to move by either selecting them all or clicking on the checkboxes of each file you wish to move by hovering your cursor to the left of them.

![](/img/help/4Fx1rJOB-VP_wD7rlq8cgcVX_ZTG68Uhbw-dfdbea8eb92a.png)

**Step 2:**  Select the 'Move Selected' button that appears in the panel

![](/img/help/NG_lC42Hjo9BvPDvSnK-ERGVrGJurd7rFQ-1a144c3f0699.png)

**Step 3:**  Click the file icon to the right of the corresponding folder you wish to move the selected files into.

![](/img/help/l6AsdCK62_l_Ld6BBBvaRWebbyPmD3RrLg-08e9c135006f.png)
