There are 4 ways to upload a file to an Embershot account.

**Option 1:** Click on the upload button in the bottom right corner and select file to upload.

![](/img/help/80FgU3Ny_QpJRIIikejZ6GzNgtHuWXLLRA-7018bff2a56a.png)

**Option 2:** Click the folder tab on the left. Click the three dots next to the corresponding folder. From the dropdown, select "Upload to Folder".

![](/img/help/XRtZmSqMek0RSOLXZVAu2PBcvsghgmeYVg-b9e2fc0f0bc6.png)

![](/img/help/ENA9AhzJjMwSQyakU7ye3MlhK81Df8KJJw-ddd574a6cdf9.png)

**Option 3:** Email files to [files@embershot.com](mailto:files@embershot.com). Files will be uploaded to your "Uploaded" folder.

**Option 4:** Select the Embershot icon when sharing through "Photos" on a mobile device. *Note: sometimes, "More" (the grey three dots on the rightmost side) may need to be clicked in order to select Embershot when sharing.*

![](/img/help/bApLyrvrIgmRd6LztoFgpVMFR0zdyCz0tg-306ca57254de.jpg)
