**Step 1:** Select the 'Files' icon

![](/img/help/7bAuURrki-maoifLQlREnAlYwQKVFO81eg-5fa509501038.png)

**Step 2:** Select the folder icon

![](/img/help/5dz295KNG4sp7wIwaCIW4qEBECmRzrox2Q-a8ed94cba04c.png)

**Step 3:** Hover over desired folder and select the more options icon

![](/img/help/XUld633oMVduoU0uSxVLlYLJ1JnW872wEg-0489219dd8b0.png)

**Step 4:** Select 'Rename'

![](/img/help/H0iyJOvzhtWfBtjcphBHX_GS-VXXZ5W_nQ-e395d893bd0c.png)

**Step 5:** Enter your new desired name and then select 'Rename' to confirm

![](/img/help/_DQGg_lAWzSmKCyO4IGV1yo0VnOtExUnCg-d8af688d5367.png)
