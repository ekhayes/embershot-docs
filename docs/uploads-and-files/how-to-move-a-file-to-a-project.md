**Step 1:** Mouse over the file that you wish to move to engage the 'More' menu.

![](/img/help/udaNAd6IlW7an9wv3kHaIytY_snaLaWugg-864122d223a2.png)

**Step 2:** Select the 'Move to Project' button that appears in the panel

![](/img/help/X70Dc6y256QrP0W6EJcIGtL9ylI0oxukeQ-5ac33b4a6ddf.png)

**Step 3:** Use the 'Projects' dropdown menu to toggle to the project where you would like to move the file.

![](/img/help/RrHCqrS3oZX9NYCL2pDX8bSdxSO_LSPQPA-f70e069aea94.png)

**Step 4:** Once a project has been selected, click the 'Move' button to move the file.

![](/img/help/gcxddw76xg1ScSU0IDJoyZoyAPPVKjBxjA-95bc842d0595.png)
