**Step 1:** Click on the 'Settings' icon for the desired file.

![](/img/help/pJcxqwNRzevTAA_AQqUrg0Q1cd_TvohJ9g-4d6fadbc990e.png)

**Step 2:** Click the 'Tags' section, enter a custom tag and hit return to save. You can create multiple tags per file.

![](/img/help/y2MpercjemKfw_Fxk7biQPAU9hlwmIWukw-d33a7e089f63.png)

**Step 3:** Saved tags appear as suggestions when tagging other files.

![](/img/help/pvLru3dkUJIWPDjJvbquM6xL7x-k8NSEqQ-d434d5bebb6b.png)

**Step 4:** Search for tagged files by clicking the 'Search' icon in the upper right corner of the console.

![](/img/help/Jw5ytSWlfX9-ExeJJyKP6c3fdFA_g_WB0w-c1097ca3308f.png)

**Step 5:** Tagged files show.

![](/img/help/QkYSwv00nxFsRR6nk6yD00-m3HWBwnyghw-c98e6906bcfc.png)
