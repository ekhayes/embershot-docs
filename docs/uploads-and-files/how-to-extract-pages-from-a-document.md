**Step 1:** Click on the three-dot 'More' menu for the desired file. From the dropdown, select 'Create Extract.'

![](/img/help/eZJDHR7uhj5PS3fyzJUr2AEEHnA2joQTSA-a14963980869.png)

**Step 2:** Enter the desired name for the new file and select the page or pages you would like to extract. Then click the 'Create Extract' button.

_Note: You can type single pages separated by a comma or you can type in ranges (Ex: 1, 3, 6-9)._
